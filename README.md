# Web → IPA

Собирает iOS-приложение (`.ipa`) из ссылки на сайт или из твоих HTML-файлов.
Сборка идёт в облаке GitHub Actions (виртуальный Mac), свой Mac не нужен.

## Как пользоваться

1. Создай на GitHub новый репозиторий и загрузи в него все файлы из этого архива
   (включая скрытую папку `.github`).
2. **Если нужна ссылка на сайт:** ничего больше не трогай.
   **Если нужен свой код:** положи файлы сайта в папку `site/` (главный файл — `index.html`).
3. (Необязательно) Положи квадратную иконку `icon.png` в корень репозитория, лучше 1024×1024.
4. Открой вкладку **Actions → Build IPA → Run workflow**, введи:
   - название приложения;
   - bundle ID (например `com.ivan.mysite`);
   - ссылку на сайт (оставь пустым, чтобы взять папку `site/`).
5. Через 3–5 минут скачай `app-ipa` из раздела **Artifacts**, распакуй zip и получи `app.ipa`.
6. Открой `app.ipa` в LiveContainer: он сам подпишет приложение.

## Что умеет приложение

- Полноэкранный WebView, свайп назад/вперёд, pull-to-refresh.
- Поддержка `alert/confirm/prompt`, `target="_blank"`, встроенного видео.
- Ссылки `tel:`, `mailto:` и т.п. открываются в системных приложениях.
- Локальный сайт из `site/` работает офлайн.
